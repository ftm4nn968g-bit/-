# Супермаркет қоймасын есепке алу жүйесі
## Magnum Cash & Carry (Java OOP жобасы)

Автор:Ainabek Togzhan
Топ:IS 24-09

Жоба туралы
Бұл — ірі супермаркеттер желісі (Magnum Cash & Carry) үшін қоймадағы тауарларды, 
жеткізушілерді, тауар қалдықтарын және жарамдылық мерзімдерін басқаруға 
арналған Java тіліндегі оқу жобасы.

### Мақсаты
Қойма жұмысын автоматтандыру: тауарларды қабылдау, сақтау, шығысқа шығару, 
мерзімі өткен тауарларды анықтау және есептілік (отчет) құру.

### Технологиялар
- Java (JDK 21)
- ООП принциптері (Инкапсуляция, Мұрагерлік, Полиморфизм, Абстракция)
- Git / GitHub
